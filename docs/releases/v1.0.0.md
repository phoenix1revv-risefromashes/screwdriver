Understand the entire robotic system—and what’s wrong with it—in under 30 seconds.

Screwdriver v1.0.0 replaces slow, fragmented robot inspection with one complete system analysis. It connects evidence across hardware, drivers, device paths, permissions, networking, processes, containers, ROS 2, and robotics software stacks—revealing what exists, what works, what is broken, and where each capability fails.

## Highlights

* Complete bottom-to-top robotic system inspection
* Immediate detection of faults, bugs, misconfigurations, and broken connections
* Local deterministic diagnostics without an API key
* Deeper agentic analysis with OpenAI or Anthropic
* Likely root causes, diagnostic commands, and step-by-step fixes
* Hardware, USB, serial, network, process, container, and ROS 2 discovery
* Capability tracing across hardware, Linux, runtime, and ROS layers
* Quick System Snapshot for immediate operational understanding
* Complete System Blueprint for full system visibility
* Engineering Diagnostic Report for structured fault investigation
* Evidence-grounded findings with confidence and provenance
* Read-only, bounded follow-up investigation
* Non-overwriting inspection history with traceable scan IDs

## Built for safe diagnosis

Screwdriver does not automatically modify configuration, restart services, install packages, activate hardware, execute repairs, or command the robot. Engineers remain in control of every system-changing action.

## Release validation

Screwdriver v1.0.0 is built and validated with Python 3.14.7. The release wheel is installed into a clean environment, its CLI is verified, and a complete passive inspection must successfully generate every expected report before the artifact is accepted.

## What’s next

Future releases will expand into active hardware verification, continuous robot monitoring, configuration-drift detection, controlled human-approved remediation, fleet diagnostics, and deeper embedded-system visibility.
