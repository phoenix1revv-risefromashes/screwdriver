# Screwdriver v1.3.0

## Universal File Analysis

Screwdriver v1.3.0 extends the existing analyze command
with support for arbitrary text-based diagnostic files.

## New capabilities

- Analyze JSON, YAML, YML, JSONL, TXT and LOG files.
- Analyze CSV, XML, INI and other UTF-8 files as text.
- Automatically recognize native Screwdriver snapshots.
- Identify multiple failures in one diagnostic file.
- Generate diagnoses using OpenAI or Anthropic.
- Validate findings against source evidence references.
- Distinguish observed failures from suspected causes.
- Generate HTML and structured JSON diagnostic reports.

## Example

screwdriver analyze inspection_log.json --provider openai

## Compatibility

Existing Screwdriver snapshot analysis remains supported.

## Safety

Custom-file analysis is read-only. It does not execute
repairs or modify robot configuration.

## Limitations

- Binary files are unsupported.
- Custom files are limited to 2 MiB.
- Some evidence may be omitted when model context limits apply.
- Model-generated diagnoses may require independent verification.
- Provider-backed analysis requires a configured API key.
