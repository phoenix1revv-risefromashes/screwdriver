# Screwdriver v1.1.0 — Find Issues

Screwdriver v1.1.0 introduces a focused issue-detection workflow for engineers who want to know what needs attention without reading the complete system inspection.

## New

### `--find-issues`

```bash
screwdriver inspect --find-issues
```

Runs the full deterministic Screwdriver inspection pipeline while displaying only actionable `WARNING` and `ERROR` findings in the terminal.

It can surface issues including:

* Hardware and device problems
* Driver and permission failures
* Misconfigurations
* Missing dependencies
* ROS 2 and runtime issues
* Network problems
* Thermal/resource warnings
* Suspicious or inconsistent system states

Informational findings are excluded from the terminal issue view.

### Agentic issue analysis

```bash
screwdriver inspect --find-issues --agentic
```

Screwdriver first detects issues deterministically, then uses the configured agentic provider to reason over those findings and supporting evidence.

Agentic analysis can provide:

* Likely root causes
* Operational impact
* Relevant evidence
* Recommended actions
* Verification steps

Existing `--provider`, `--model`, and `--effort` controls remain supported.

## Behavior

The complete inspection still runs in `--find-issues` mode.

Full snapshots, reports, logs, and diagnostic evidence continue to be generated and preserved. The new flag changes the terminal presentation, not the underlying inspection depth.

Existing `inspect`, `inspect --local`, `inspect --agentic`, and `analyze` workflows remain backward compatible.

## Upgrade

```bash
pip install --upgrade screwdriver-robotics
```

Requires Python 3.11+.
